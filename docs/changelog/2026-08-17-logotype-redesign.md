# 2026-08-17 — Logotype redesign

The `DESCKO.` mark was rejected and redrawn from a supplied reference. Everything that
carries the mark was regenerated to match.

## What changed

The mark was condensed Bebas Neue, heavy, with a dark maroon stop. It is now **Archivo
Medium at `0.22em` tracking with a vermilion (`#B3382C`) stop** — wide-set and quiet, the
air between the letters doing as much work as the letters.

| | Before | After |
| --- | --- | --- |
| Face | Bebas Neue (condensed display) | Archivo Medium |
| Tracking | `0.045em` | `0.22em` |
| Stop | Maroon `#6B1A2A`, round-ish | Vermilion `#B3382C`, square |
| Proportion | ≈ 3 × cap height wide | ≈ 6.5 × cap height wide |

## Files

Regenerated by `node tools/brand/build-brand-assets.mjs public/brand`:

- All 26 files in `public/brand/` — 6 colourways × (SVG + PNG at 600/1200/1800 px), plus the
  1200 × 630 Open Graph card.
- `public/favicon.svg`, which was still a Bebas `D.`.

Generator changes:

- `tools/brand/Archivo-Medium.ttf` vendored in; `tools/brand/BebasNeue-Regular.ttf` removed —
  nothing uses it any more, including the Open Graph tagline, which is now Archivo too.
- The generator now also writes `public/favicon.svg`, so the favicon can no longer drift away
  from the wordmark. It was previously produced by hand and was the one asset that got missed.
- The tight crop now trims the full stop's right side bearing. The advance width of `.`
  overhangs its ink, which at `0.22em` tracking left a visible strip of dead space on the
  right of every transparent wordmark.

## In the app

The header and footer render the wordmark as live text, not an image, so they had to move
too — otherwise the site would still be showing the rejected mark.

- `src/index.css`: new `.wordmark` utility (Archivo 500 / `0.22em` / uppercase), and a
  `--vermilion` token.
- `tailwind.config.js`: `vermilion: '#B3382C'`.
- `Navbar.jsx`: `.font-display .tracking-display` → `.wordmark`, stop recoloured maroon →
  vermilion. Type size dropped `text-2xl sm:text-3xl` → `text-xl sm:text-2xl`; Archivo at the
  old size is more than twice as wide as condensed Bebas and would have crowded the nav.
- `Footer.jsx`: same swap, `text-4xl` → `text-2xl sm:text-3xl`.

## Deliberately not changed

- **The footer stop stays amber.** Vermilion on charcoal is legible but subdued; amber was
  already chosen for contrast on the dark band and that reasoning still holds. The exported
  `descko-lockup-charcoal-bg` uses vermilion, so this is a known, documented divergence.
- **Bebas Neue is still the heading face.** `--font-heading` / `--font-display` and every
  heading on the site are untouched. Only the logotype moved.
- **Maroon is still the UI red** (`text-maroon`, focus rings, `--destructive`). Vermilion is
  scoped to the stop.

## Verification

`npm run lint` and `npm run build` both clean. Each regenerated PNG was rendered and compared
against the reference by eye.
